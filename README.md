# MySend

局域网内，把电脑上的文件夹**单向同步**到 Android 手机/平板。一套 Flutter 代码同时编译出
**Windows 桌面端（发送端）**与 **Android 端（接收端）**，UI 采用 Windows 11 风格的磨砂玻璃
（Acrylic / Mica）视觉。

MySend 面向「电脑 → 手机」这一最常见的单向归档场景：无论是音乐、照片、文档还是其他文件，
只要把电脑上的目录与手机上的目录做一次映射，之后**新增**的文件就能按映射自动同步过去。

## 下载

预编译产物由 GitHub Actions 自动构建，并随每次 Release 提供，前往
[Releases](https://github.com/WinGua/MySend/releases) 下载最新版本：

- **Windows（发送端）**：`MySend-Windows-x64.zip`，解压后运行 `MySend.exe`。
- **Android（接收端）**：`MySend-Android.apk`，传到手机侧载安装。

## 特性

- **单向同步**：仅「电脑 → Android」，不做反向或设备间互传。
- **只同步新增**：仅同步手机端尚不存在的文件；手机端已存在的同名文件会被跳过、
  不会重复下载；**完全不处理删除**，手机端多出的文件不会被自动清理，需自行手动管理。
- **多组映射**：可手动配置任意多组「电脑目录 ↔ 手机目录」，两端以映射「名称」配对，
  传输时按**相对路径**对齐，两端根目录可各自独立配置。
- **局域网直连 + 扫码配对**：UDP 广播自动发现设备；电脑端可「创建连接二维码」，
  手机端「扫码添加设备」，广播失效也能快速配对。
- **连接确认**：一方发起连接后，对端弹出确认弹窗，同意后建立连接。
- **双端双向操作**：电脑端、手机端都能发起「连接」「对比」「同步」全套流程（传输方向仍固定为电脑 → 手机）。
- **结果可视化**：对比完成展示新增文件清单（超 3 个自动省略）与总数；同步中显示进度条，
  成功手动关闭、失败展示原因。
- **机型识别**：连接 / 本机按真实形态展示电脑、平板、手机图标。
- **手机后台保活**：Android 端以前台服务 + 常驻通知保活，切后台 / 黑屏不掉线。
- **同步日志**：设置页记录每次同步的任务名、时间、文件数与总大小，自动清理 7 天前记录。
- **关于与更新**：内置「关于 MySend」介绍页、「GitHub 仓库」快捷跳转，以及
  「检查更新」一键比对最新版本。
- **响应式界面**：手机端使用底部导航，平板 / 桌面端自动切换为 Win11 侧边栏。
- **现代视觉**：Windows 11 风格磨砂玻璃（Acrylic）UI——毛玻璃卡片、悬浮毛玻璃底部导航、
  滑动指示器动画、深浅渐变背景。
- **跨端统一**：一套 Dart 代码，Windows 与 Android 共用同一套 UI 与同步逻辑。

## 工作原理

1. 发送端扫描源目录，为每个文件建立索引（相对路径、大小、修改时间）。
2. 接收端扫描自己的目标目录，建立同样结构的索引。
3. 两端索引按「相对路径」对齐比对：
   - 发送端有、接收端没有 → **新增** → 传输
   - 接收端已有 → **跳过**（不重复下载、不比对内容、不处理删除）
4. 确认差异清单后，通过局域网 HTTP 把新增文件从电脑传输到手机对应目录。
   （当前为明文 HTTP，尚未启用 TLS 加密）

## 使用说明

### 电脑端（发送端）

1. 运行 `MySend.exe`，进入「映射」页点击「添加映射」。
2. 「名称」填一个两端能对上的键（如 `音乐`、`文档`），「源目录」点「浏览」选择电脑上的对应文件夹。
3. 保持程序运行，它会自动广播并作为发送端监听。

### Android 端（接收端）

1. 安装 APK，进入「设置」→「申请文件访问权限」，授予「允许访问所有文件」；
   并点「允许后台运行（推荐）」以避免切后台掉线。
2. 「映射」页添加**同名**的映射，「目标目录」填手机真实路径
   （如 `/storage/emulated/0/Music`）。
3. 回到「状态」页，通过「扫码添加设备」或自动发现找到电脑，点「连接」；
   电脑端会弹出确认，同意后建立连接。
4. 点每组映射的「对比」查看新增文件，再点「同步」。

> 两端映射的「名称」保持一致即可配对；不想同步的目录直接不配置。

## 已知限制与说明

- **传输为局域网明文 HTTP**，未加密，仅建议在可信的局域网内使用。
- **Windows 可执行文件未签名**，在其他电脑首次运行会弹出 SmartScreen，
  点「更多信息 → 仍要运行」即可。
- **APK 使用固定 release 签名**，支持覆盖安装升级；若要上架 Google Play，
  需自行配置正式签名与商店账号。
- **Android 端需要「所有文件访问」权限**来直接写入真实目录；若要上架 Google Play，
  需改用 SAF（文件夹选择器授权）方案。
- **广播发现**在个别路由器下可能失效，可用「扫码配对」兜底。
- **手机后台保活**依赖前台服务常驻通知；Android 15+ 对 `dataSync` 前台服务有
  每日时长上限，属个人同步工具的可接受范围。
- 少数国产系统（如 vivo OriginOS）对全屏 / 挖孔区域有系统级限制，
  可能需要在系统「屏幕顶部显示」里把本应用设为「显示前置摄像头」。
